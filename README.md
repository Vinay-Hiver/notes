# Prototype starter (HOT design system)

A ready Vite and React project with the HOT components, tokens and icons.

```bash
npm install
npm run dev
```

`COMPONENTS.md` is the list of components, tokens and page recipes. `CLAUDE.md` tells Claude how to use them. This folder is refreshed from the main repo by `npm run agent-docs`, so do not edit the component folders here: change them in the Storybook repo.
